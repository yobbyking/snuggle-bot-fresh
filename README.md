# Snuggle X Bot

Clean, working WhatsApp bot built with Baileys.

## Features
- ✅ Fake contact card on .menu (🚫𝔖𝔫𝔲g𝔤𝔩𝔢 𝔵☠️)
- ✅ Channel forwarding on all replies (Snuggle X channel)
- ✅ CYPHER-X style menu with "Read more"
- ✅ SQLite for settings (persistent)
- ✅ Owner/sudo/user access control
- ✅ Works in DM and groups
- ✅ .song / .video (yt-dlp)
- ✅ .sticker / .url / .vv
- ✅ .ai (Gemini AI)
- ✅ .tagall / .hidetag / .promote / .kick
- ✅ .calc / .qr / .uuid / .pass / .hash
- ✅ Anti-call

## Setup

```bash
npm install
node bot.js <sessionFolder>
```

## Commands

### Public
- `.menu` — Main menu (with contact card + readmore)
- `.all` — Full command list
- `.ping` — Latency check
- `.alive` — Bot status
- `.help` — Quick help

### Owner
- `.mode` — Change bot mode
- `.setprefix` — Set command prefix
- `.setownername` — Set owner name in menu
- `.addsudo` — Add sudo user
- `.tagall` — Tag all members
- `.song` — Download YouTube MP3
- `.video` — Download YouTube MP4
- `.sticker` — Convert image to sticker
- `.ai` — Ask Gemini AI
- `.calc` — Calculator
- `.qr` — QR code generator
